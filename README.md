## ✨ Recursos

- ⏱️ **Intervalos Configuráveis**: Defina de quanto em quanto tempo deseja receber os alertas.
- 🔔 **Notificações do Navegador**: Alertas visuais e sonoros nativos na área de trabalho.
- 📱 **Modo Offline & Instalável (PWA)**: Funciona 100% offline e pode ser instalado no celular (Android/iOS) ou no desktop como aplicativo nativo.
- 🔒 **Zero Coleta de Dados**: Todas as preferências e contagens ficam salvas exclusivamente no `localStorage` do seu navegador.

---

## 🚀 Como Testar Localmente

Basta abrir o arquivo `index.html` em qualquer navegador ou subir um servidor local rápido:

```bash
python3 -m http.server 8000
# Acesse no navegador: http://localhost:8000
```
